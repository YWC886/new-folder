# Reynolds 修正 vs 逐桨先验：公开数据对标 v0.5

- 版本：v0.5（2026-11-21）
- 代码：[`code/reference/re_correction.py`](../../code/reference/re_correction.py)、[`test_re_correction.py`](../../code/reference/test_re_correction.py)
- 数据：UIUC Propeller Database Vol.1 静态数据，7 桨 / 112 点（同 v0.2/v0.3/v0.4）
- 边界声明：REFERENCE（风洞测量）对标，**不是本项目实测**，不构成校准或验证结论；本页所有误差均为**样本内**（同一批点拟合+评估），不是泛化评估。

## 1. 目的

v0.2–v0.4 揭示：通用参数化模型（`ct0=0.110, aT=-0.02, cp0=0.045, aP=-0.035`）相对 UIUC 数据存在系统性偏差——

- C_T：7 桨有 6 桨实测随 RPM 上升，模型缓降（方向相反）；
- C_P：模型一致偏低但幅度因桨而异（2.9%–37.3%）。

v0.4 用逐桨先验把样本内误差压到 0.3–1.5%，但代价是"必须先知道目标桨型的 C_T0/C_P0"。本版回答中间问题：

> **只加一个与几何无关的 Reynolds 修正，能否修正上述偏差？**

## 2. 方法

Re 采用工程定义 `Re = n·D²/ν`（n 为 rev/s），基准状态 `Re_ref = n_ref·D_ref²/ν`，`n_ref=100 rev/s`、`D_ref=0.2544 m`（10 英寸）；ν 由 Sutherland 公式 + 理想气体密度取 24 °C / 96 kPa（≈1.57×10⁻⁵ m²/s）。

两个变体（都只用 7 桨合并的 2 个参数）：

1. **替换式**（`re`）：跨桨 pooled 拟合 `C_T = ct0·(Re/Re_ref)^a`、`C_P = cp0·(Re/Re_ref)^b`，直接用 pool 结果替换通用模型；
2. **乘性修正**（`scaled`）：保留通用模型系数，再乘 `(Re/Re_ref)^a`，指数 a 由 `log(实测/通用)` 对 `log(Re比)` 过原点回归（CT 与 CP 各一个指数）。

对比三方：`generic`（现状默认）、`re`、`scaled`，并把 v0.4 的 `prior`（逐桨 REFERENCE 先验）作为上界参照。

## 3. 结果

### 3.1 pooled 拟合质量

| 系数 | c0 / 指数 | R² | 说明 |
|---|---|---|---|
| C_T pooled | 0.1172 / **+0.0911** | **0.046** | 方向为正，但几乎解释不了方差 |
| C_P pooled | 0.0518 / **−0.0807** | **0.027** | 方向为负，同样解释力极低 |
| 乘性修正 | CT **+0.0203**，CP **−0.2458** | — | 极小/中等量级的趋势修正 |

结论先行：**单一 Re 幂律几乎解释不了跨桨数据**（R²≈0.03–0.05），因为同 Re 下不同几何（直径、螺距、翼型）的 C_T/C_P 相差可达 2 倍。

## 4. 解读

1. **Re 修正不能替代逐桨参数。** 两条 Re 路线相对逐桨先验差一个数量级（CT 11% vs 0.8%；CP 14% vs 0.9%）。
2. **替换式在 CT 上反而略变差**（11.37%→11.81%）：pooled 拟合被高 C_T 的 apcsf 拉偏，对其它桨无益；CP 有改善（16.8%→13.6%）但收益不稳定（apce_11x7 从 2.9% 恶化到 19.0%）。
3. **乘性修正更稳但收益有限**（CT 11.0%、CP 14.2%）：它只在全局上修正趋势，无法处理"几何差异"这一主导因素。
4. **物理含义**：本数据 Re 范围约 1.4×10⁵–4.7×10⁵（变化 3.3 倍），Re 效应真实存在（CT 略升、CP 略降），但**量级远小于几何差异**；想用通用模型准确预测，必须引入几何参数化（直径/螺距/翼型）或目标桨型的参考数据。
5. **对项目的意义**：这些结果把"通用模型 → 目标机型校准"的必要性钉死。实测效率地图前，仿真只能作为趋势/先验；选型与节能结论必须等 M0.4 标定与目标桨型数据。

## 6. 限制与下一步

- 样本内、单批次 UIUC 数据，未做留出验证（v0.2/v0.4 已说明该库差异；留出需更多桨型或风洞新测）；
- 未纳入翼型/螺距/实度等几何特征（若做，属于"参数化代理模型"方向，可作为 v0.6 候选）；
- 乘性修正的指数同样是全样本拟合，存在过拟合风险；
- 本版结论不写入 `propulsion_model.ModelParams` 默认值（D033/D034/D042 延续），仅作参考性记录；
- v0.6 候选：几何特征回归（直径/螺距/实度 → ct0/cp0/aT/aP）、Reynolds+Mach 双修正、留出验证。
