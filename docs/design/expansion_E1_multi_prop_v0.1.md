# 拓展 E1 实施方案：多桨型横向对比 v0.1

> 2026-11-21 ｜ 依据 `docs/规划/开题拓展方向_v0.1.md` E1；不改变申报 135 工况基线，仅在悬停/巡航工作点加密。

## 1. 目的与假设

- 目的：回答"同推力下换桨型，整链效率差多少、值不值得换桨"。
- 假设：同直径不同螺距、或 10→11 寸变化，在悬停/巡航工作点 η_sys 差异可达数个百分点；差异需大于测量不确定度才有工程意义。

## 2. 桨型选择（建议）

| 编号 | 桨型 | 直径/螺距 | 匹配电机 | 备注 |
|---|---|---|---|---|
| P1 | 10×4.5（基线） | 254×114 mm | 400 KV 级 | 现有 SIM10x4.5 对照 |
| P2 | 10×6 | 254×152 mm | 400 KV 级 | 同直径变距 |
| P3 | 11×7 | 279×178 mm | 380–400 KV 级 | 变径，检查推力裕度/电流 |

参考：UIUC 静态数据已含 apce_11x7（先验可作仿真预筛，do_not_apply）。

## 3. DoE 设计（开题后首轮）

- 电压：11.1 / 14.8 / 22.2 V（3 档）
- 油门：30 / 50 / 75 / 100 %（4 档，聚焦悬停–巡航段）
- 桨型：P1 / P2 / P3（3 支）
- 重复：3 次（含重新装夹）
- 合计：**3×4×3×3 = 108 次运行**；单次 5 s（预热 2 s + 稳态 3 s）→ 约 9 min 纯采集（不含换桨/冷却）
- 命令：`py -3.12 code/processing/design_matrix.py --voltages 11.1,14.8,22.2 --throttles 30,50,75,100 --props P1,P2,P3 --repeats 3 --output data/processed/design_matrix_E1.csv --summary data/metadata/design_matrix_E1.summary.json`
- 目标推力模式（可选）：`--thrust-levels 2,3,5 --map-prop P1` 生成等推力对照（需先有 P1 实测地图）。

## 4. 采集与分析链路

1. 每桨：双人装夹检查（桨夹力矩、动平衡目视）→ 按排程运行；
2. 每 10 次：检查零漂与温度（绕组/环境温升 >5 ℃ 暂停）；
3. 处理：`measured_readiness.py` → `compute_efficiency.py --require-measured` → `aggregate_efficiency.py --require-measured`；
4. 对比：同推力插值（`gp_match`/`match_propulsion`）比较 η_sys 与电流；按桨型分组作图；
5. 判据：η_sys 差 ≥2% 且超过 2 倍合成不确定度 → 记为有意义差异；否则记为"无显著差异"。

## 5. 判据与验收

| 指标 | 目标 |
|---|---|
| 标定 | R²≥0.9995；重复性/迟滞 ≤0.5% FS |
| 单点重复性 | 3 次 η_sys 相对标准差 ≤2% |
| 对比显著性 | 差异 ≥ max(2%, 2·U(k=2)) |
| 温升控制 | 每工况起点绕组温度 ≤ 环境+8 ℃ |

## 6. 风险与预案

- 桨夹不匹配 11 寸桨 → 先采购适配桨夹或改 P3 为 10×7；
- 大桨径推力裕度不足/电流超限 → 降低电压档位或油门上限；
- 换桨引入零点漂移 → 每次换桨后空载读数记录并在处理时扣除。
