## 1. 设计目标与范围

- 测量对象：单轴「电机—螺旋桨—电调」动力系统，推力级 0.5–2 kg（约 5–20 N），桨径 8–18 寸。
- 测量量：推力 T（N）、反扭矩 Q（N·m）、转速 n（r/min）、母线电压 U（V）、电流 I（A）、电机温度、环境温湿压。
- 目标不确定度（U，k=2）：推力 ≤1.0%、扭矩 ≤2.0%、转速 ≤0.1%、电压/电流 ≤0.5%（与 bench_tech.md 的不确定度预算一致）。
- 不做的事：六分量力、旋转扭矩传感器、风洞级流场控制——留作方案 B / 后续升级。

## 3. 总体布局

```text
              ┌──────────────┐   ← 5 mm PC 防护罩（600×600×600，可拆卸）
              │   螺旋桨      │
              │      │       │
              │   ┌──┴──┐    │   ← 电机座（8 mm 铝板 / 3D 打印夹具）
              │   │电机 │    │
              │   └──┬──┘    │
              │   ┌──┴──┐    │   ← S 型拉压力传感器（推力通道，量程 0–10 kg）
              │   │传感 │    │
              │   └──┬──┘    │
        ┌─────┴──────┼──────┴─────┐
        │   4040 铝型材框架底座     │   ← 地脚 + 减振垫，可调水平
        └─────────────────────────┘
   反扭矩臂：从电机座沿水平方向伸出 L = 0.25 m，顶住 0–50 N 拉压力传感器
   （或直接选用 0–5 N·m 旋转扭矩传感器，二选一，见 §5）
```

- 立式布置：推力沿竖直方向，避免桨叶尾流受地面反射（桨盘中心离地 ≥1.5D）。
- 传感器下置：推力传感器装在电机座与底座之间，受拉/压均可（S 型拉压传感器），更换电机座不影响传感器。
- 整机可放在实验室台面上，也可落地；底座预留配重/固定孔。

## 4. 结构设计与关键约束

| 约束 | 要求 | 理由 |
| --- | --- | --- |
| 桨盘中心离地 | ≥1.5D（18 寸约 0.69 m） | 减小地面效应 |
| 下游（下方）遮挡 | 1D 内无障碍物 | 减小尾流阻塞 |
| 台架一阶固有频率 | ≥3×BPF（BPF = n/60 × 叶片数） | 避开桨叶通过频率共振；n=6000 r/min、2 叶时 BPF=200 Hz，一阶 ≥600 Hz 较难 → 按实测/仿真校核，必要时降低目标转速上限 |
| 电机座挠度 | <0.1 mm（最大推力下） | 避免推力测量偏载、桨盘偏摆 |
| 传感器同轴度 | 推力作用线与传感器轴线偏心 <1 mm | 减小弯矩与侧载 |
| 反扭矩臂 | L = 0.25 m，力臂刚度足够，端部低摩擦顶块 | 把扭矩转为可测力；摩擦引入误差 ≤0.2% |
| 电机座材料 | 8 mm 6061 铝板（或 5 mm 碳板） | 刚度/加工/成本平衡 |
| 框架 | 4040 铝型材 + 角件，底座加配重 | 快速调整、可拆装、可复现 |

## 5. 反扭矩测量方案对比（待 11-21 决策）

| 方案 | 器件 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- | --- |
| A. 反扭矩臂 + 拉压力传感器 | 0–50 N S 型 + L=0.25 m 臂 | 便宜（约 300–600 元）、量程可分档、易标定 | 力臂摩擦与端部接触误差、需限位 | **v0.1 默认** |
| B. 旋转扭矩传感器 | 0–5 N·m 动态扭矩 | 直接测轴扭矩、无臂误差 | 贵（数千元起）、需联轴器与动平衡 | 预算不足，不做一期 |

> 若选方案 A：扭矩 Q = F × L，L 用卡尺实测（标定报告记录）；传感器量程按最大反扭矩 Q_max 估算（例如 2 N·m / 0.25 m = 8 N，选 0–20 N 档更稳）。

## 6. 安全设计（红线）

1. **防护罩**：360° 5 mm 透明 PC 罩，顶部与四周封闭，正面可开合（带联锁或至少双人确认）。
2. **急停**：急停按钮串入电调供电回路（接触器/继电器），按下即断电，不经过软件。
3. **双人**：任何通电旋转测试 ≥2 人在场，一人操作、一人监护。
4. **桨叶检查**：每次上电前检查桨叶裂纹、紧固件扭矩、电机座螺钉。
5. **电池安全**：LiPo 用防火袋/防爆箱，充电有人值守；优先用可编程电源替代电池做长时测试。
6. **线缆**：动力线与信号线分开走线，应力释放，避免桨叶刮碰。
7. **场地**：室内风速 <0.5 m/s，无关人员撤离到防护罩外 2 m。

## 9. 风险与备选

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 台架共振 | 数据不可用、结构疲劳 | 仿真+逐步升速测试，必要时加筋/配重 |
| 传感器偏载 | 推力读数偏大/偏小 | 球头/万向节传力，标定含偏载检查 |
| 反扭矩臂摩擦 | 扭矩系统偏差 | 低摩擦顶块（POM/轴承），重复性测试 |
| 预算不足 | 加工/采购缩水 | 优先保推力与采集，反扭矩二期补 |
| 加工周期 | 12 月联调延期 | 先用 3D 打印件做功能验证，铝件后补 |
