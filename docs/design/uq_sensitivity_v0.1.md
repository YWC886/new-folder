# U(k=2) 对选型 Pareto 的敏感性分析 v0.1（SIM）

> 版本：v0.1（2026-11-23）｜状态：草稿｜边界：SIM 原型，不是选型结论（D056/D057/D059）

## 1. 目的

回答一个评审必问的问题：**测量不确定度 U(k=2) 取不同值时，选型结论会不会变？**
工具对同一批 SIM 效率地图数据，在 U(k=2) ∈ {0, 0.01, 0.02, 0.0226, 0.03, 0.05} 下分别重算保守效率并重排 Pareto 前沿，输出 knee 与 Top-1 的迁移。

## 2. 方法

1. `multiobjective.run_pareto` 生成基准前沿（推力 5 N ±10%，13×41 网格）；
2. 对每个 U：`u_meas = U/2`，`σ_total = sqrt(u_meas² + σ_gp²)`，`η_cons = η − 2σ_total`，按 `η_cons` 重排 rank；
3. 记录 knee（前沿首选点）与 Top-1 的电压/油门/保守效率。

## 3. 结果（SIM，5 N ±10%）

| U(k=2) | knee | η_sys | η_cons(2σ) |
|---|---|---|---|
| 0 | 21.89 V / 72.5% | 0.4738 | 0.4672 |
| 0.01 | 21.89 V / 72.5% | 0.4738 | 0.4618 |
| 0.02 | 21.89 V / 72.5% | 0.4738 | 0.4527 |
| 0.0226 | 21.89 V / 72.5% | 0.4738 | 0.4502 |
| 0.03 | 21.89 V / 72.5% | 0.4738 | 0.4431 |
| 0.05 | 21.89 V / 72.5% | 0.4738 | 0.4233 |

**结论：**在当前 SIM 前沿上，U(k=2) 从 0 加到 0.05 只让保守效率下降约 4.4–5.8 个百分点，**knee 位置完全不变**。说明候选之间的效率差（效应量）远大于测量不确定度带来的排序扰动——即选型结论对该区间的 U 取值稳健。反过来说，若两个候选的保守效率差小于 2σ（约 0.023–0.03），才需要按"不可区分"处理。

## 5. 限制与后续

- 仅 SIM 前沿（单桨型 10×4.5、16 工况）；实测后应换用 MEASURED 地图重跑；
- U 固定作用于所有候选点，未考虑不同电压/电流档位的量程误差差异；
- 结论"knee 不变"依赖当前前沿的效应量，若实测前沿更平，U 可能改变排序——这正是敏感性分析要监控的。
