# 效率地图 v0.4：GP 平滑代理与交叉验证

> 状态：草稿（2026-11-19）；实现 `code/processing/gp_surface.py`；测试 12 项。
> 输入仅为 **SIM 效率地图**（16 个仿真工况），不产生实验结论。

## 1. 目的与边界

v0.1–v0.3 的效率地图以离散网格点呈现（4 电压 × 4 油门）；v0.4 用高斯过程（GP）在
电压—油门二维空间做平滑代理，回答三个问题：

1. 离散点之间/附近的 η_sys 大致是多少（均值面）？
2. 哪些区域代理模型置信低（预测标准差）？→ 指导后续补测/加密仿真点；
3. 用留一交叉验证（LOOCV）给平滑质量一个可复核的误差指标。

**边界**：GP 预测是"对现有数据的平滑"，不是物理模型；外推区（超出数据范围）不得用于选型或安全结论；
预测标准差 ≠ 测量不确定度 U(k=2)。

## 2. 方法

- 输入特征归一化：`x = (V/30, throttle/100)`；
- 核函数：RBF `k(x,x') = σ_f²·exp(-||x-x'||²/(2ℓ²)) + σ_n²·δ`，σ_f²=1、σ_n²=1e-5；
- 超参数：核宽 ℓ 在 `{0.05, 0.10, …, 1.00}` 上网格搜索，取 **LOOCV RMSE 最小**；
- LOOCV 闭式解：`r_i = α_i / (K⁻¹)_ii`，`loo_i = y_i − r_i`；
- 预测：`μ(x*) = k*ᵀ(K+σ_n²I)⁻¹(y−ȳ) + ȳ`，`σ²(x*) = σ_f² − k*ᵀ(K+σ_n²I)⁻¹k*`；
- 输出：21×21=441 点网格的 `eta_pred`、`eta_std`，双面板图（均值热力图 + 预测标准差热力图）。

## 3. 数据与结果（2026-11-19，SIM）

| 项 | 值 |
| --- | --- |
| 输入 | `data/processed/efficiency_map_runs.csv`（16 点，全部 `source=SIM`） |
| 选中核宽 | **ℓ = 0.550** |
| LOOCV RMSE | **0.001662** |
| LOOCV R² | **0.9999** |
| 网格 | 21×21 = 441 行 → `data/processed/efficiency_map_surface_v0.4.csv` |
| 图件 | `data/processed/figures/efficiency_map_v0.4.png`（1875×720，约 105 KB） |

观察：

- 16 个点几乎落在光滑曲面上，LOOCV 误差约 0.0017（η_sys 绝对量级），说明离散工况本身高度一致；
- 预测标准差在观测网格线附近最低（约 0.003），在电压/油门边界与角点升高（约 0.010），与"外推不可信"的直觉一致；
- 均值面显示：同电压下 η_sys 随油门单调升；同油门/推力下电压越高 η_sys 越高；低功率角趋近空载效率。

## 4. 复现命令

```powershell
# 需先有 runs.csv（来自 aggregate_efficiency.py）
py -3.12 code\processing\gp_surface.py --overwrite
# 或指定参数（固定核宽、网格点数）
py -3.12 code\processing\gp_surface.py --length-scale 0.55 --grid 21 --overwrite
# 测试
py -3.12 -m unittest discover -s code\processing -p "test_gp_surface.py" -v
```

## 5. 验收

- 12 项测试通过：数据读取（含 aggregate 的 `eta_sys_mean` 兼容）、训练点插值误差 <1e-4、LOOCV 指标、
  核宽搜索确定性、网格输出字段/行数、CSV/PNG 覆盖保护、错误输入；
- 本机实测：LOOCV RMSE 0.001662、R² 0.9999，网格 CSV 441 行、图件含 SIM 红字。

## 6. 限制与后续

1. 仅 16 个 SIM 点，GP 置信主要反映"数据覆盖"，不能证明物理正确性；
2. 核为各向同性 RBF，未做各向异性/Matérn 对比，也未优化 σ_n²；
3. 未把 GP 标准差与标定不确定度 U(k=2) 合成；未接入选型匹配（v0.5 计划：GP 均值 + 保守 η 的分层候选）；
4. 实机地图到位后需用 MEASURED 数据重跑，并复核外推区（高电压/低油门）是否物理合理。
