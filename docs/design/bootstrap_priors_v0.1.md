# Bootstrap 不确定度 v0.1：UIUC 逐桨先验的稳健性检查

- 版本：v0.1（草稿）
- 日期：2026-11-19
- 负责人：D（Lead 复核）
- 关联：`code/reference/bootstrap_priors.py`、`docs/design/public_data_benchmark_v0.3.md`、D031、D033、D034
- 数据来源：UIUC Propeller Database, Vol.1 静态数据（`data/reference/uiuc/`，7 桨 / 112 点，REFERENCE）

## 1. 目的与边界

v0.3 用 7 桨静态数据反推了逐桨 `ct0/a_T/cp0/a_P`，但每桨只有约 16 个点：**这些参数本身有多稳？** 本工具用逐点重采样 bootstrap 回答：

- 输出每个参数的 95% 百分位区间、反推误差的区间；
- 检查"a_T 方向与通用先验相反"这一结论是否依赖个别点。

**边界（重要）**：bootstrap 只反映"16 点内部的重采样波动"，不含 UIUC 风洞系统误差、桨型/加工差异、测试条件差异；**它不是测量不确定度 U(k=2)**，不能与 `compute_efficiency` 的不确定度块相加或比较（D034）。区间偏乐观，仅用于量级参照的稳健性检查。

## 2. 方法

- 每桨：从 16 个点中有放回抽样 16 个点，重拟合 log-OLS `CT=ct0·(n/n_ref)^aT`、`CP=cp0·(n/n_ref)^aP`；
- 重复 `--n-boot` 次（默认 200），记录参数样本与"在原始 16 点上的平均绝对相对误差"样本；
- 95% 区间取线性插值百分位（`--ci` 可调，默认 0.95）；
- 随机种子固定（默认 20261119），逐桨按序派生，保证可复现；
- pooled 先验单独重采样（种子 +7919）。

## 4. 结论

1. **"a_T 方向相反"是稳健结论**：7/7 桨的 a_T 95% CI 全部位于 0 以上，且远离通用先验的 −0.02（图中虚线），不是个别点造成的。
2. **桨型差异是真实的**：如 APC-SF `ct0=0.160` 与通用 0.110 的差距远超其 CI（约 ±0.0005）；逐桨先验的必要性得到区间支持。
3. **内误差量级稳健**：CT 内误差 CI 上限约 1.7%、CP 约 1.9%，与点估计（0.3–1.5%/0.5–1.2%）同量级。
4. **pooled 先验不稳健**：pooled a_T 的 95% CI 为 [+0.028, +0.177]，覆盖范围很宽，进一步说明跨桨单一先验不可靠（v0.3 已显示 pooled C_T 反而更差）。
5. **不是实验不确定度**：本区间无法回答"实机效率地图的 U(k=2)"；后者由 `compute_efficiency` 的一阶传播（先验 U）与 M0.4 实测标定共同决定。

## 6. 限制与 v0.2 待办

| 限制 | 说明 |
|---|---|
| 只含采样波动 | 不含风洞系统误差、桨型/加工/表面差异；区间偏乐观 |
| 每桨 16 点 | bootstrap 分布粗糙；区间端点对个别点敏感 |
| 确定性种子 | 单次 200 次的结果有蒙特卡洛误差（可增大 n-boot 检查） |
| 与 U 不可比 | 不得与 `compute_efficiency` 的 U(k=2) 相加/比较（D034） |

v0.2 候选：① 增大 n_boot 做收敛检查；② 参数联合置信椭圆（ct0–aT 相关）；③ 对 pooled 做分层 bootstrap（按桨分层）；④ 与 M0.4 实测标定区间同图对比。
