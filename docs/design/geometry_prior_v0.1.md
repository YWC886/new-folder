# 螺旋桨几何特征代理模型（Geometry-Feature Prior）v0.1

日期：2026-11-22　状态：已完成（REFERENCE 负结果）　决策：D049

## 1. 目的与边界

用 UIUC 公开静态数据（8 桨型 / 112 点，REFERENCE）拟合「几何 + 转速」特征的线性代理，
以留一桨型（leave-one-prop-out, LOPO）交叉验证检验：**仅凭几何量（直径 D、螺距比 P/D）与转速，能否比通用参数模型更好地预测 C_T / C_P？**

- 数据为 REFERENCE（UIUC 风洞），不是本项目实测，不构成本项目结论；
- 代理模型只作论文建模章节的方法学对照，不写入 `ModelParams` 默认值（D042/D049 语义）；
- 本项目主线口径仍为「同一桨型、不更换桨型」（v4 申报口径）。

## 2. 方法

特征：`x = [1, D, P/D, n_norm, n_norm²]`，`n_norm = n_rps / 100`。
线性模型：`C = θᵀx`，OLS 求解；C_T、C_P 分别拟合。
验证：LOPO——用其余 6 个桨型拟合，预测被留出桨型，逐点相对误差取平均，再对 7 桨求 pooled 均值。
对照：通用参数模型 `ModelParams`（ct0=0.110, cp0=0.0450, a_T=−0.02, a_P=−0.035）。

## 3. 结果（7 桨 / 112 点，LOPO）

| 指标 | 通用先验 | 几何特征 LOPO | 变化 |
|---|---|---|---|
| C_T 平均绝对相对误差 | **11.37%** | **19.21%** | 变差 +7.8 pp |
| C_P 平均绝对相对误差 | **16.68%** | **19.61%** | 变差 +2.9 pp |

逐桨（C_T / C_P，通用→LOPO）：apce_11x7 5.69→4.26 / 2.86→11.82；apce_11x8 8.02→52.06 / 11.66→37.45；
apcsf_10x7 26.51→26.54 / 37.33→25.95；apcsp_9x6 6.46→8.61 / 21.00→7.03；grcp_10x6 15.62→8.26 / 7.83→10.50；
grsn_10x7 13.95→10.05 / 23.45→5.05；ance_8.5x6 3.35→24.72 / 12.60→39.47。

## 4. 结论（诚实负结果）

1. 仅用几何量线性代理在 LOPO 下**不能**稳定优于通用先验（pooled C_T 变差、C_P 持平）；
2. 原因：7 个桨型的 D 与 P/D 高度相关（几何共线），留一桨型时线性模型只能做外推，
   而实际偏差由系列/翼型/雷诺效应主导（与对照分析与 bootstrap 结论一致）；
3. 个别桨型有明显改善（apce_11x7 的 C_T、grcp 的 C_T、apcsp/grsn 的 C_P），说明几何特征含局部信息，
   但不足以跨桨型泛化；
4. 因此：论文中该模型只能作为「方法学对照/负结果」，不能作为预测工具；主线仍建议
   「同一桨型实测地图 + GP 平滑」。

## 6. 数据诚信与限制

- 全部为 REFERENCE 数据；不得表述为实测或本项目结论；
- 线性模型、无翼型极曲线、无雷诺数显式项（n_norm 仅近似转速效应）；
- 7 桨型样本量小，LOPO 统计波动大；
- 后续（v0.2 候选）：加入翼型/弦长分布特征，或改用叶素动量（BEM）物理模型，
