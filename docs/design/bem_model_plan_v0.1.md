# 叶素动量（BEM）桨模型 v0.1 设计说明（规划稿）

日期：2026-11-22　状态：设计稿（尚未实现）　承接：D049 几何代理负结果

## 1. 动机

几何特征线性代理在留一桨型验证中失败（C_T 11.37%→19.21%，C_P 16.68%→19.61%，D049）。
下一级建模升级采用**叶素动量理论（BEM）**：以桨几何（弦长、扭角分布）与翼型极曲线为输入，
物理地预测静态 C_T、C_P 及转速趋势，再与 UIUC REFERENCE 对照，检验「物理模型是否比纯几何回归更可迁移」。

## 2. 模型（静态悬停，轴向诱导）

对半径 r 处叶素（N 个叶素，等距或余弦分布）：

- 入流角 `φ = arctan(V_i / (Ωr))`，静态 V_∞≈0；
- 攻角 `α = θ(r) − φ`；
- 升阻系数 `C_l(α)`、`C_d(α)` 由翼型极曲线给出（初版用 Clark-Y/Airfoil 近似表：薄翼 + 平板阻力 + 失速截断）；
- 叶素推力 `dT = 0.5ρW²c·(C_l cosφ − C_d sinφ)·B·dr`，扭矩 `dQ = 0.5ρW²c·(C_l sinφ + C_d cosφ)·B·r·dr`；
- 诱导速度由动量定理闭合：`dT = 4πρ V_i(V_i + V_∞) r dr`，用不动点/割线迭代求 V_i(r)；
- 总 T、Q 积分；效率相关量按 D012 口径（P_shaft=QΩ）。

## 3. 输入与数据

- 桨几何：直径 D、桨毂半径、弦长分布 c(r)、扭角 θ(r)、叶数 B。初版用 APC 10x7E 的公开几何近似（按 UIUC 几何页/公开资料整理，标注 REFERENCE-GEOM），
  其余桨型用「系列缩放 + 已知 D 与 P/D」参数化近似，不宣称精确几何；
- 翼型极曲线：低 Re（10⁴–10⁵）平板/薄翼近似 + Cl_max 截断，明确为近似值；
- 验证数据：UIUC 8 桨静态点（REFERENCE）。

## 4. 验证协议

1. 代码：`code/reference/bem_propeller.py`；单测 ≥10 项（叶素积分守恒、V_i 收敛、CT/CP 正值、悬停不退化解、已知简化算例）；
2. 对照：APC 10x7E 上 C_T/C_P 相对误差（目标 ≤20%，作为「物理模型可比几何回归」的底线）；
3. 迁移：对其他 6 桨用同一几何近似策略（仅 D、P/D 已知）预测，报告误差；
4. 判定：若物理模型在留出桨型上优于几何回归（19.21%/19.61%），则论文采用 BEM 作为「可解释建模」候选；否则如实记录负结果。

## 5. 风险与边界

- 几何近似误差可能主导结果，必须标注 REFERENCE-GEOM，不得表述为实测；
- 低 Re 极曲线近似、静态无来流、忽略桨尖损失初版（可选 Prandtl 修正 v0.2）；
- 不接入仿真主线（ModelParams 不变），仅作论文建模对照；实机后需以实测几何/极曲线重跑。
