# 大创申报「项目附件」清单分析与建议（v0.1）

> 日期：2026-11-20
> 依据：①《关于开展 2026 年第三批"高峰领航计划"暨本科生萌创项目立项工作的通知》（已解压核实）；②《西北工业大学大学生创新创业训练计划管理系统使用指南（申报立项）--学生》；③ 申报系统「项目附件」页（支持 .doc/.docx/.pdf/.rar/.zip）。
> 结论先行：**申报阶段没有强制附件**——通知未要求提交任何附件材料，系统学生指南中附件上传为可选操作；但建议上传 2–4 份支撑材料，帮助评审专家快速了解项目基础与可行性。

## 3. 不建议上传的内容

- 与项目无关的课程作业、社团材料、个人简历；
- 含个人隐私（身份证号、手机号完整）或涉密/敏感信息；
- 未经标注的模拟结果（必须标 SIM / REFERENCE，避免被误认为实测）；
- 完整 257 页软著材料（体积大、与评审无关；如需要只放封面/目录 2–3 页）。

## 4. 操作与提交注意事项（你自行提交时）

1. 上传后**必须等"上传成功"提示**，再点"暂存"或"提交"；若替换，直接上传新文件后再暂存/提交。
2. 「暂存」可反复修改；「提交」后不能修改 → 建议先暂存核对，再提交。
3. 提交后状态变为"学生提交项目"，需**提醒指导教师审核**（教师先完成电子签名，再审核通过/退回）；学院须在 **12 月 4 日前**完成审核提交。
4. 申报批次为"2027 年大学生创新创业训练计划项目"、类别"萌创项目"；确保成员（≤5 人）与指导教师已在第 2 步正确选择。
5. 若学院有额外要求（如纸质签字版），以学院通知为准；本清单结论仅基于学校通知与系统指南。
