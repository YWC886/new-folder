## 3. 精读笔记（每篇一节）

### Lxxx 标题

- **问题**：作者要解决什么？
- **方法**：台架/仿真/数据方法、关键公式。
- **数据**：测试对象、工况范围、样本量。
- **结论**：可直接引用的结论（带页码）。
- **局限**：作者承认或可看出的局限。
- **对本项目的用处**：支撑哪一章/哪个参数/哪个决策。
- **可复现点**：公式、表格、图能否复算。

## 4. 引用与查重注意

- 规划文档与申报书引用处标 `[编号]`，文末统一参考文献表；

- 每周四把新增文献（编号 + 一句话结论）发 A 汇总。
