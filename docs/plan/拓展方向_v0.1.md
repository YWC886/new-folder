## 2. 方向二：公开数据对标（无需自有硬件）

**目的**：在实机数据缺失期，建立"我们的效率量级/趋势是否与公开数据同量级"的检查层，同时为选型匹配提供参考。

- 数据源候选：UIUC 螺旋桨数据库（推力/功率系数随 advance ratio）、公开电机台架测试（如 RC 电机效率表）、厂商数据表；
- 产出：`data/reference/`（只读参考数据 + 来源/许可证说明）、`code/processing/compare_reference.py`（量级/趋势对比）、报告一节"与公开数据对标"；
- 纪律：`data/reference/` 与 `data/raw/` 严格分开；引用必须注明来源与许可证；不得把公开数据包装成本项目实测；
- 验收：≥2 个桨型的公开曲线入库，输出对比表 + 差异解释（桨型、雷诺数、测量方法差异）。
- **2026-11-19 完成 v0.1**：UIUC Vol.1 APC 10x7E 静态样本（16 点）入库，`code/reference/uiuc_propdb.py` 解析器 + `benchmark_uiuc.py` 模型 CT/CP 对标（C_T 均值误差 6.14%/最大 14.65%，C_P 均值 13.83%/最大 14.95%，模型系统性低估 C_P），9 项测试，产物 `data/processed/uiuc_benchmark_v0.1.{csv,png}`；v0.2 扩多桨型、风速扫描（J/CT/CP/η）与通用 `compare_reference.py`。
- **2026-11-19 完成 v0.2**：多桨型目录对标——7 个新 UIUC 静态文件 + 原样本共 8 桨/112 点（3 品牌/6 系列，RPM 1,655–6,897），`catalog_uiuc.py`（per-prop + pooled 统计、逐点/逐桨 CSV、分组图），18 项测试；pooled C_T 绝对均值 11.37%（带符号 −0.69%）、C_P 16.68%（带符号 −13.62%）；7 项结论见 `docs/design/public_data_benchmark_v0.2.md`（C_P 系统性低估跨桨一致、偏差按系列主导、7/7 桨实测 C_T 随 RPM 上升而模型缓降）；剩余：更多桨型/风速扫描、Re 修正、cp0/ct0 按桨型反推。
- **2026-11-19 完成 v0.3**：逐桨参数反推 `calibrate_uiuc.py`——7 桨 log 空间 OLS 反推 `ct0/a_T/cp0/a_P`（n_ref=100），输出逐桨 CSV + `uiuc_priors_v0.3.json`（`do_not_apply:true`）；内误差 0.3–1.5%（C_T）/0.5–1.2%（C_P），7 桨 a_T 全为正（通用 −0.02 方向相反），pooled C_T 11.90%/C_P 14.13%；10 项测试（参考共 28 项）；文档 `docs/design/public_data_benchmark_v0.3.md`（D033）。
- **2026-11-19 完成 v0.1 bootstrap**：`bootstrap_priors.py` 逐点重采样 200 次/桨，输出 95% CI；7/7 桨 a_T CI 均在 0 以上并远离 −0.02，pooled a_T CI [+0.028,+0.177] 很宽；区间非 U(k=2)（D034）；10 项测试（参考共 38 项）；文档 `docs/design/bootstrap_priors_v0.1.md`；剩余：Re 修正、与实测标定同图对比、联合置信椭圆。
- **2026-11-21 完成 v0.4 prior-profile**：`prior_profile.py` 把逐桨先验包装成 opt-in `ModelParams`，同数据（7 桨/112 点）对比通用 vs 逐桨先验：C_T 11.37%→0.3–1.5%、C_P 16.68%→0.5–1.2%（样本内上限，非泛化/非实测）；10 项测试（参考共 48 项）；D042、文档 `docs/design/prior_profile_v0.1.md`。
- **2026-11-21 完成 v0.5 Reynolds 修正（负结果）**：`re_correction.py` 以 `Re=n·D²/ν` 检验单一 Re 幂律能否解释 7 桨数据：替换式 pooled 拟合 CT R²=0.046 / CP R²=0.027，乘性指数 CT +0.0203 / CP −0.2458；7 桨均值 CT 11.37%→10.96%（替换式 11.81%）、CP 16.68%→14.17%（13.62%），均远差于逐桨先验 0.78%/0.92% → 几何主导、Re 修正不可替代逐桨/实测；13 项测试（参考共 61 项）；D044、文档 `docs/design/re_correction_v0.5.md`；剩余：几何特征回归（v0.6，留出验证）、与实测标定同图对比、联合置信椭圆。

- **2026-11-19 完成 v0.1**：离散网格匹配（推力公差/油门上限/电压/来源筛选 → 去重 → η_sys 排序 → Top-N），SIM 端到端（5 N ±10% → 2 候选，图件 `data/processed/figures/selection_v0.1.png`），全程 SIM 标注；

- **2026-11-19 完成 v0.3**：`gp_match.py` GP 连续匹配（thrust/η 双 GP → 每电压油门扫描 → `σ_gp` 与 U 合成保守效率），14 项测试（选型共 34 项）；SIM 演示 5 N ±10% → 3 个 GP 候选（22.2 V/68.2% 第一），产物 `data/processed/selection_v0.3_gp.csv`、`data/processed/figures/selection_v0.3.png`；
- **2026-11-19 完成 v0.4**：`multiobjective.py` 真多目标 Pareto（13×41 候选、η/电流/保守 η 非支配筛选、knee=29.60 V/52.5%、28 可行/5 前沿）+ GP σ 补测点推荐（5 点、限定已测油门区间），9 项测试（选型共 43 项），SIM 演示 5 N ±10%；产物 `data/processed/selection_v0.4_pareto.csv`、`data/processed/gp_suggestions_v0.4.csv` 与图件 `selection_v0.4.png`、`gp_suggestions_v0.4.png`；v0.5 见下条（成本项、重量/噪声/寿命目标仍待真实产品参数表）。
