## 2. 开发目的

面向多旋翼无人机动力系统（无刷电机—螺旋桨—电调）的效率评测与选型，提供从**原始传感器数据**
到**效率指标**、**效率地图**、**候选方案匹配**、**公开数据对标**与**仿真先验**的一体化软件工具链，
支撑台架试验数据管理与后续选型优化，降低人工换算与重复计算误差。

## 4. 主要技术特点

1. **效率口径统一**：η_em = P_shaft/P_elec；FM = P_ideal/P_shaft（P_ideal = T^1.5/√(2ρA)）；η_sys = FM·η_em；
   空气密度优先用实测温压，缺省 1.204 kg/m³；禁止 T/P 简化口径。
2. **数据可信标记**：所有仿真合成数据（SIM）与公开参考数据（REFERENCE）在文件名、meta、CSV 列与图件中强制标注，
   与实机测量数据物理隔离，避免误用为实验结论。
3. **只增不改**：原始 CSV 与产物默认拒绝覆盖（`--overwrite` 显式放行）；汇总保留 `source=SIM/MEASURED` 列。
4. **可复现**：脚本化生成、固定随机种子、schema 版本化（效率汇总 schema 0.2）、依赖版本锁定。
5. **质量保障**：分模块单元测试 210 项（采集 5、处理 72、仿真 29、选型 47、参考 38、工具 19），
   覆盖正常路径、边界、错误输入、覆盖保护与产物格式；并提供一键 CI（`run_all_tests.py`）与提交前一致性检查（`check_release.py`）。

## 6. 典型运行命令

```powershell
# 采集（模拟）
py -3.12 code\acquisition\acquire.py --mode simulate --run-id 20261119_SIM_22.2V_50pct_R1 `
    --duration 2.5 --sample-rate 1000 --combo SIM10x4.5 --voltage-set 22.2 --throttle-set 50

# 效率计算（稳态自动识别 + 不确定度）
py -3.12 code\processing\compute_efficiency.py --input data\raw\<run_id>.csv `
    --calib data\metadata\calib_SIM_PHYS10x4.json --steady auto --steady-window 0.5

# 地图汇总/成图（含 U 误差棒）与 GP 平滑代理（v0.4）
py -3.12 code\processing\aggregate_efficiency.py --dir data\metadata --overwrite
py -3.12 code\processing\plot_efficiency_map.py --uncertainty --overwrite
py -3.12 code\processing\gp_surface.py --overwrite

# 仿真战役（16 工况）与热瞬态
py -3.12 code\simulation\simulate_campaign.py --force
py -3.12 code\simulation\transient_thermal.py --overwrite
py -3.12 code\simulation\two_node_thermal.py --overwrite

# 选型匹配（v0.2：3 N ±5%，均衡目标）
py -3.12 code\selection\match_propulsion.py --input data\processed\efficiency_map_runs.csv `
    --thrust 3.0 --tolerance 0.05 --objective balanced --overwrite

# 选型匹配（v0.3：5 N ±10%，GP 连续匹配）
py -3.12 code\selection\gp_match.py --input data\processed\efficiency_map_runs.csv `
    --thrust 5 --tolerance 0.1 --objective eta_sys --overwrite

# 选型匹配（v0.4：真多目标 Pareto + GP σ 补测点推荐）
py -3.12 code\selection\multiobjective.py --input data\processed\efficiency_map_runs.csv `
    --thrust 5 --tolerance 0.1 --overwrite
py -3.12 code\selection\multiobjective.py --input data\processed\efficiency_map_runs.csv `
    --suggest --n 5 --min-distance 0.12 --overwrite

# 公开数据对标（单桨 + v0.2 多桨目录）
py -3.12 code\reference\benchmark_uiuc.py --reference data\reference\uiuc\apce_10x7_static_pg0811.txt --overwrite
py -3.12 code\reference\catalog_uiuc.py --reference-dir data\reference\uiuc `
    --output data\processed\uiuc_benchmark_v0.2.csv --summary data\processed\uiuc_benchmark_v0.2_summary.csv `
    --figure data\processed\figures\uiuc_benchmark_v0.2.png --overwrite

# 公开数据对标 v0.3：逐桨参数反推（REFERENCE-derived priors，do_not_apply）
py -3.12 code\reference\calibrate_uiuc.py --overwrite

# 公开数据对标 v0.1 bootstrap：逐桨先验 95% CI（REFERENCE 稳健性检查，非 U(k=2)）
py -3.12 code\reference\bootstrap_priors.py --overwrite

# 一键 CI（六套测试合跑）与提交前一致性检查（测试 + 清单 SHA256 + 源代码页新鲜度）
py -3.12 code\tools\run_all_tests.py
py -3.12 code\tools\check_release.py
```

## 7. 测试与验证记录（2026-11-19）

- 全部分模块测试：**210 项通过**（采集 5、处理 72、仿真 29、选型 47、参考 38、工具 19；命令见 `docs/softcopyright/README.md` §3）。
- 一键 CI 与提交前检查：`run_all_tests.py` 六套合跑 210 项全绿、exit 0；`check_release.py` 在真实仓库上输出「测试 210 / 清单 142 文件 SHA256 一致 / 源代码页 44 文件 11,833 行 237 页无过期」，exit 0（D038/D039）。
- 关键闭环验证：
  - 仿真→流水线的一致性与量级闭环：v0.1 战役 16 工况推力相对误差 <0.3%、η_sys <1.6%（噪声主导）；
  - UIUC 对标（v0.1 单桨）：C_T 相对误差均值 6.14%（最大 14.65%），C_P 均值 13.83%（最大 14.95%），
    说明通用参数先验偏"高效"，需按目标桨型校核；
  - UIUC 对标（v0.2 多桨）：8 桨/112 点 pooled C_T 绝对均值 11.37%（带符号 −0.69%）、C_P 16.68%（带符号 −13.62%，系统性低估），
- 逐桨反推（v0.3）：7 桨内误差 C_T 0.3–1.5% / C_P 0.5–1.2%；7 桨 a_T 全为正（通用先验 −0.02 方向相反）；输出 `uiuc_priors_v0.3.json` 固定 `do_not_apply:true`（仅参照，非本项目标定）。
- bootstrap 不确定度（v0.1）：7/7 桨 a_T 的 95% CI 均在 0 以上且远离 −0.02；pooled a_T CI [+0.028,+0.177] 很宽；该区间非 U(k=2)、不可与流水线 U 相加（D034）。
    7/7 桨实测 C_T 随 RPM 上升而模型缓降 → cp0 水平与转速趋势需按桨型重标定；
  - 选型 v0.2 演示：3 N ±5% 得到 3 个插值候选，均衡目标下 22.2 V/52.0% 排序第一；
  - 选型 v0.3 演示：5 N ±10% 得到 3 个 GP 候选，22.2 V/68.2% 第一（保守效率已扣 σ_gp 与 U）；
  - 选型 v0.4 演示：5 N ±10% 得到 28 个可行候选、5 个 Pareto 前沿点（knee 29.60 V/52.5%），并给出 5 个 GP σ 补测建议；
- 仿真 v0.4 演示：22.2 V 满油门 300 s + 停机 300 s，绕组峰值 82.9 °C、机壳 66.2 °C（单节点低估绕组约 2.9 K），冷却至 35 °C 用时 132 s；
- GP 平滑代理（v0.4）：16 SIM 点、LOOCV RMSE 0.001662、R² 0.9999（核宽 0.550），21×21 预测均值/标准差面。
- 未完成验证：实机串口采集、砝码静态标定、台架动态测量（受硬件条件限制，另行开展）。
