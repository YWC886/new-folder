# 复现包清单 V1.0

> 对应软件《多旋翼动力系统效率地图构建与匹配优化软件》V1.0（2026-11-19 代码状态）。
> 本包目标是**可复核**：源码、文档、参考数据与关键产物齐全，环境与校验步骤明确；
> 不包含 `work/pylibs` 依赖、大体积原始数据与二进制发行物。

## 1. 包内结构

```
code/            源码 54 个文件（.py + 说明）
  acquisition/   采集与只读校验
  processing/    效率流水线与效率地图（含 GP 平滑代理、静态砝码标定拟合）
  simulation/    物理仿真、仿真战役、热瞬态
  selection/     选型匹配（含补测策略对比）
  reference/     公开数据对标（单桨 v0.1 + 多桨目录 v0.2 + 逐桨参数反推 v0.3 + bootstrap CI v0.1 + prior-profile v0.4 + Re 修正 v0.5，do_not_apply）
  tools/         软著/复现材料生成器、一键 CI、提交前一致性检查与 MEASURED 端到端演练
docs/            过程文档（设计、采购、输入确认、测试、计划、research、软著材料、申报/规划/参考归档等）
data/reference/  UIUC 公开参考数据小样本 9 个文件（含来源/许可说明）
data/processed/ 小体量汇总产物与图件清单相关文件 38 个
README.md 等根目录说明 1 个
```

由 `code/tools/build_manifest.py` 生成的清单：
`data/processed/release_manifest_v0.1.csv`（**171 个文件，约 8.2 MiB**，逐文件 SHA256）。
清单只收文本类交付物（≤2 MB），排除图片/Office/PDF/zip、`work/`、`__pycache__` 与清单自身。

## 2. 复现步骤（最小）

```powershell
# 0) 前置：Python 3.12.x；依赖安装到 work\pylibs（见 docs/参考/软件环境与使用说明.md §2.3）
$env:PYTHONIOENCODING = 'utf-8'

# 1) 环境自检
py -3.12 work\env\check_env.py

# 2) 全部分模块测试（当前 277 项：采集 5 / 处理 91 / 仿真 29 / 选型 62 / 参考 61 / 工具 29）
foreach ($d in 'acquisition','processing','simulation','selection','reference','tools') {
    py -3.12 -m unittest discover -s "code\$d" -p "test_*.py" -v
}

# 3) 关键产物复现（示例：16 工况仿真战役 → 效率地图 → 选型）
py -3.12 code\simulation\simulate_campaign.py --force
py -3.12 code\processing\plot_efficiency_map.py --uncertainty --overwrite
py -3.12 code\selection\match_propulsion.py --input data\processed\efficiency_map_runs.csv `
    --thrust 3.0 --tolerance 0.05 --objective balanced --overwrite

# 4) 公开数据对标复现
py -3.12 code\reference\benchmark_uiuc.py --reference data\reference\uiuc\apce_10x7_static_pg0811.txt --overwrite

# 5) 材料再生成（源代码页 + SHA256 清单）
py -3.12 code\tools\source_pages.py --out-dir docs\softcopyright\build --overwrite
py -3.12 code\tools\build_manifest.py --output data\processed\release_manifest_v0.1.csv --overwrite
# 6) 提交前一致性检查（六套测试 + 清单 SHA256 + 源代码页新鲜度；全部通过 exit 0）
py -3.12 code\tools\check_release.py

# 7) MEASURED 端到端演练（临时合成夹具：门禁→流水线→汇总→选型 + SIM 负向对照，6 项检查；默认不落盘仓库）
py -3.12 code\tools\measured_e2e_drill.py
```

## 3. 完整性校验

```powershell
py -3.12 -c "import csv,hashlib,pathlib; rows=list(csv.DictReader(open('data/processed/release_manifest_v0.1.csv',encoding='utf-8'))); bad=[r['rel_path'] for r in rows if hashlib.sha256(pathlib.Path(r['rel_path']).read_bytes()).hexdigest()!=r['sha256']]; print('files:',len(rows),'mismatch:',bad[:5])"
```

预期输出 `files: 169 mismatch: []`。

## 5. 明确不包含的内容

- `work/pylibs/`（依赖库，按 `work/env/requirements.txt` 重装）、`work/` 下一次性脚本与临时图；

- 二进制/Office/PDF 成品（申报表、docx 规划文档、预览 PDF）——另行按项目文档归档管理；
- 任何实机标定/测量数据（目前尚未产生，相关流程在 `docs/test/` 与 `docs/inputs/`）。
