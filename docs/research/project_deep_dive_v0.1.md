## 0. 结论摘要（TL;DR）

1. **软件侧已形成完整、可复现的研究原型**：环境可复现，6 个代码模块、**134 项测试全部通过**（2026-11-19 现场复跑：acquisition 5 / processing 38 / simulation 29 / selection 43 / reference 9 / tools 10），覆盖"采集→处理→地图→仿真→选型→对标→软著材料生成"全链路。
2. **硬件与实测侧基本为零**：`data/` 下 **17 个 raw 采集全部是 SIM**（`mode=simulate`、`simulated=true`），`data/metadata/` 中只有 1 个 validation 与 2 个 **合成**标定 JSON（`calib_SIM_DEMO`、`calib_SIM_PHYS10x4`）；静态砝码读数记录为**空白模板**；`efficiency_map_runs.csv` 16 行全部 `source=SIM`。**项目目前没有一条 MEASURED 数据。**
3. **申报书（附件 3 大一新生版）承诺 6 项预期成果、其中数据集"不少于 500 组工况"、2~3 套推荐方案需台架验证**；规划 v1.1 给出 G1–G6 量化验收指标（2027-03 至 2027-10）。当前真实差距集中在 G1/G2（台架与数据集）这一**硬件关键路径**，G3–G5 的软件方法已就位但全部缺少实测输入。
4. **近期唯一硬约束是 2026-11-21/11-25/11-27 三个里程碑**（关键输入冻结、BOM+3 家询价、最小采集链路+静态砝码读数）。这三项直接决定 12 月能否下单、2027-03 能否完成台架验收，进而决定整个 2027 年时间表是否成立。
5. 风险排序：**①硬件链路与砝码标定未验证（含安全）→ ②仅 SIM、仿真参数未辨识导致结论不可外推 → ③关键输入未冻结引发的工期连锁风险**；软著"初稿、未提交、学校信息待补"与预算口径差异（7000 vs 10000 元）为次级风险。

### 1.3 申报书列出的 4 个关键问题

出处：申报表 PDF 第 8 页。

1. 系统级效率的准确测量与解耦（小推力/小扭矩信噪比低、多通道同步易受干扰、电池电压跌落）；

4. 台架结果向真实飞行工况的外推修正（来流、安装干扰、电池放电）。

### 3.2 六大风险（按优先级）

**R1 硬件链路与砝码标定未验证（最高优先级，影响安全与全部数据可信度）**
- 现状：`docs/test/采集链路自检报告_v0.1.md` 自述 5 条局限——模拟模式不经过传感器/ADC/串口/时钟；未做砝码静态标定（raw 计数→N/N·m 换算系数未知）；时间戳未验证 MCU 时钟抖动；未测 EMI/丢包/隔离接地；校验通过只代表格式/连续性/采样率/稳态性符合规则。
