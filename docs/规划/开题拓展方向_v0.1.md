# 开题后拓展方向 v0.1

> 2026-11-21 ｜ 依据新版申报书（`docs/申报/申报表/申报表-修改版_v3草稿.docx`）与现有成果（281 项测试软件原型、调研/对标/数据资产）梳理。
> 定位：开题后的可执行拓展清单，逐项标注所需条件与判据；不改变申报书主目标。

## 1. 拓展方向（按优先级）

| # | 方向 | 具体做法 | 所需条件 | 判据 |
|---|---|---|---|---|
| E1 | 多桨型横向对比 | 台架下 2–3 支桨（如 10×4.5 / 10×6 / 11×7），同工况测效率差异 | 桨夹/桨备件（BOM 已含） | 同推力下 η_sys 差 ≥2% 判定为有意义 |
| E2 | 温升—效率耦合 | 长时悬停工况：记录绕组/定子温度与效率漂移，建立温升修正项 | K 型热电偶、连续采集 | 效率漂移与温升回归 R²≥0.8 |
| E3 | 控制分配验证 | 同一总推力下不同转速分配（单/双电机）测电功率差，验证"分配节能"仿真结论 | 双电机台架（需扩展 BOM） | 实测量级与仿真差 ≤30% |
| E4 | 巡检作业量换算 | 把效率差换算为"单架次塔数/换电次数"，做任务级敏感性分析 | 目标机型参数（电池容量/航时） | 输出 1–2 张任务级对照表 |
| E5 | 数据与复现开放 | 发布数据集说明 + 复现包（保留 SIM/REFERENCE 标注），供评审/后续团队复用 | 数据脱敏与许可证确认 | 他人按 README 可一次跑通 |

## 2. 与申报书主线的衔接

- E1/E2 属于 S2–S3 阶段加测，不改变 135 工况基线，只在选定的悬停/巡航点加密；
- E3 依赖双电机台架，建议作为 2027 寒假备选（预算外需另行申请或借用设备）；
- E4 属 S4 应用示例延伸，可用现有 SIM 数据先出模板，实测后替换；
- E5 复用现有 `release_package.py` / `check_release.py` / 复现包清单。

## 3. 开题答辩要讲清的三件事

1. 为什么必须整机测：部件相乘丢电调/压降/耦合（用 UIUC 对标与仿真说明）；
2. 为什么先做地图不做通用最优：地图是"按工作点查询"的工程依据，避免不可行的联合寻优；
3. 为什么低年级能做：已有 281 项测试的软件原型 + SOP + 分工，剩余风险集中在硬件与时间。
