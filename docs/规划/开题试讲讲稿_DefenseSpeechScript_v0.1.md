# 开题试讲讲稿 _DefenseSpeechScript_v0.1

配套 `开题答辩PPT_v0.1.pptx`（17 页）与 `开题答辩要点_DefenseKeyPoints_v0.1`。目标时长 8–10 分钟。

## 逐页讲稿（要点句）

1. 封面：项目名 + 3 人小组 + 指导教师 + 日期，一句话报题。
2. 背景：巡检场景中续航/换电是硬约束，而"电机—桨—电调"整体效率不透明。
3. 问题：部件级效率无法相乘得到整链效率；缺乏宽工况系统级数据；选型多凭经验。
4. 现状：部件表征（Piljek 2020、Cox 2025）→ 地图与优化（Nam 2023、Røstum 2026）→ 整链闭环（本文目标）。
5. 目标：在真实工作点测系统效率，建带不确定度的效率地图，用它做悬停/巡航选型。
6. 内容六环节：调研 → 台架 → 测试 → 建模 → 分析 → 复测。
7. 台架方案：单轴立式 + 反扭矩臂，推力/扭矩/转速/电压电流同步采。
8. 标定：双人 M1 砝码静态标定，R²≥0.9995、重复性/迟滞≤0.5%FS。
9. DoE：3 电压×5 油门×3 桨×3 重复=135 次；反解目标推力排程。
10. 建模：机理先验 + GP 平滑（LOOCV 选核宽），给 U(k=2)。
11. 地图：电压×油门×桨型，悬停/巡航两点应用示例。
12. 对标与校验：UIUC 8 桨 112 点仅量级/趋势核查；逐桨先验 do-not-apply。
13. 已有基础：软件原型 281 项测试、SIM/REFERENCE 方法与工具链。
14. 进度：申报→采购→台架→测试→地图→复测→结题，2026-11 至 2027-10。
15. 风险：采购延迟、标定超差、温升/压降漂移、台架外推；各附缓解。
16. 预期成果：台架 1 套、数据集 1 套、模型+地图、报告 1 份、可交接资料（论文/软著为可选）。
17. 致谢 + 请评审提问（预留 E1 多桨、E2 温升、E3 分配负结果三张备用页）。

## 必须声明的边界

- 当前结果均为 SIM/REFERENCE，非实机；实测将在 M0.4 后替换。
- 不承诺"节能 X%"；分配节能实验为负结果（非均匀分配总功率上升）。
