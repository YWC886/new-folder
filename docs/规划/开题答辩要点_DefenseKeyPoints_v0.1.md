# 开题答辩要点 _DefenseKeyPoints_v0.1

> 依据：`docs/申报/申报表/申报表-修改版_v3草稿.docx`、`docs/规划/开题答辩PPT_v0.1.pptx`、`docs/规划/申报书对比分析与优化研究路径_v0.1.md`。
> 状态：v0.1 草稿，供 3 人小组试讲与导师预审；本材料不含实机结论。

## 1. 一句话立题

本项目把「电机—螺旋桨—电调」当作一个整体，在真实工作点上测出系统效率，画成可查询的效率地图，并用它回答巡检场景的选型问题。

## 2. 要讲清的三个问题（评审最可能追问）

| 问题 | 回答要点 |
|---|---|
| 为什么不是单件相乘？ | 单件效率受工况耦合影响，电调损耗与电机温升不可简单相乘；整链测量才能给出系统级 η。 |
| 效率地图怎么用？ | 给定推力需求（悬停/巡航），按电压与油门查 η、电流与不确定度，比较候选桨型与供电电压。 |
| 和已有工作差在哪？ | 已有工作多为部件级或仿真选优，缺少「实测—建模—地图—应用—复测」闭环（D012/D026/D043）。 |

## 3. 方法与进度（当前为 SIM/REFERENCE 原型）

1. 台架与标定：拉压力/扭矩传感器 + 24 bit ADC + 串口，双人砝码标定（M1）。
2. DoE：3 电压 × 5 油门 × 3 桨 × 3 重复 = 135 次运行（`design_matrix.py`）。
3. 建模：机理模型 + GP 平滑（LOOCV 选核宽），带 U(k=2) 不确定度。
4. 应用：悬停/巡航两工作点比较；补测策略 σ/EI（`bo_suggest.py`）。
5. 复测：复测值与地图预测偏差需落在重复性离散度内。

## 4. 答辩时必须声明的边界

- 所有效率/选型/仿真结果当前均为 **SIM（合成）或 REFERENCE（UIUC 公开数据）**，不是本项目实测；
- 实机数据将在 M0.4 最小链路 + 双人砝码标定后按 MEASURED 通路入库并重跑；
- 分配节能（E3）为 **负结果**：同一总推力下非均匀分配在本 SIM 面上总功率上升，不得宣称节能。

## 5. 下一步三件事

1. 冻结被测对象（电机/电调/桨/电池/电压点）与场地电源；
2. 完成 M0.4 测力/扭矩链路与标定，产出第一份实测标定与实测数据；
3. 用实测数据替换地图 v1.0 与论文占位表，形成结题材料。
