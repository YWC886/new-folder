# M0.4 启动包 · M0.4 Kickoff Pack v0.1

> 目标：把"最小采集链路 + 双人砝码标定 + MEASURED 数据入库"所需的全部材料、命令与验收判据集中到一处。
> 现状：软件链路已就绪（230+ 项测试全绿），**硬件与标定尚未开始**；本包不含任何实测数据。

## 1. 采购与到货（B 负责）

- [ ] 按 `docs/procurement/bom_v0.1.md` 确认必需项（推力/扭矩传感器、24 bit ADC、转速、电压电流测量、机架与防护、砝码、电源）；
- [ ] 按 `docs/procurement/询价单模板.md` 向 3 家供应商询价，比价表填回；
- [ ] 下单并记录订单号/到货时间；到货后核对型号与量程，录入 `docs/procurement/bom_v0.1.md`。

## 2. 台架与接线（B 主责，C 复核）

- [ ] 按 `docs/design/bench_v0.1.md` 组装：桨盘离地 ≥1.5D、下游 1D 无遮挡、电机座挠度 <0.1 mm；
- [ ] 按 `docs/design/数据采集方案_DAQ_v0.1.md` 接线：传感器 → ADC → 串口；
- [ ] 防护罩、急停（串电调供电回路）、电池防火、双人在场；
- [ ] 空载上电自检：串口 11 列协议输出、采样率 ≥990 S/s、各通道无 NaN。

## 3. 标定（B、C 双人，A 复核）

- [ ] 打印并填写 `docs/test/静态砝码读数记录_v0.1.md`（加载/卸载各 6 点 ×3 次）；
- [ ] 用模板 `data/metadata/templates/calibration_readings_template.csv` 录入读数（长表：channel,direction,repeat,applied,raw）；
- [ ] 生成标定：
  ```powershell
  py -3.12 code\processing\calibration_fit.py --input <读数.csv> --output data\metadata\calib_MEASURED.json --diameter 0.2544
  ```
- [ ] 判据（不通过则复标）：R² ≥0.9995、重复性/迟滞 ≤0.5% FS、空载噪声 ≤0.1 N；
- [ ] 双人签字 + A 复核，记录 `docs/test/` 留存。

## 4. MEASURED 通路验证

```powershell
# 1) 门禁
py -3.12 code\processing\measured_readiness.py --input <raw.csv> --calib data\metadata\calib_MEASURED.json

# 2) 处理（必须拒绝 SIM/REFERENCE）
py -3.12 code\processing\compute_efficiency.py --input <raw.csv> --calib data\metadata\calib_MEASURED.json --window 3 --require-measured

# 3) 汇总 / 地图
py -3.12 code\processing\aggregate_efficiency.py --dir data\metadata --require-measured
py -3.12 code\processing\gp_surface.py --input data\processed\efficiency_map_runs.csv
```

- [ ] 首条 MEASURED 数据入库（`data/raw/` + `.meta.json` 的 `mode=serial, simulated=false`）；
- [ ] `data/processed/<run>_efficiency.json` 中 `simulated=false`。

## 5. 首次采集（SOP）

- [ ] 按 `docs/test/试验执行SOP_v0.1.md`（一页速查版可贴台架）执行；
- [ ] 单工况：预热 30 s → 稳态 3 s → 记录；温升 >5 ℃ 暂停冷却；
- [ ] 每工况重复 3 次；异常（振动/异味/异响/超温）立即急停并记录。
