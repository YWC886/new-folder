# 台架试验执行 SOP · 一页速查版 v0.1

> 贴墙用 · 完整版见 `docs/test/试验执行SOP_v0.1.docx` · 双人执行、签字存档（A/B/C 分工见分工表）

## 红线（任何一条不满足即禁止上电）

- 防护罩到位、急停可切断电调供电（每次上电前实测一次）；
- 至少 2 人在场；上电期间不得拆装、不得越罩取物；
- 电池无鼓包/异味；电池防火袋、灭火毯就位；
- 桨叶无裂纹、紧固件扭矩复核；桨盘离地 ≥1.5D、下游 ≥1D 无遮挡；
- 现场禁止工具杂物堆放，线缆远离旋转面。

## 一、上电前 6 查

| 序号 | 检查项 | 责任 |
|---|---|---|
| 1 | 防护罩、急停、双人到位 | B |
| 2 | 桨叶/桨夹/电机座紧固与动平衡 | B |
| 3 | 台架调平对中、下游净空 | B |
| 4 | 线缆应力释放、接地屏蔽 | C |
| 5 | 电源限流/过压保护设定 | C |
| 6 | 环境温压湿记录（算空气密度） | C |

## 二、双人砝码标定（M1 等级，0/20/40/60/80/100% FS）

1. 加载逐级记录，每点稳定后读 3 次；
2. 卸载逐级记录（用于迟滞）；
3. 反扭矩通道同法，记录力臂 0.25 m；
4. 现场拟合 `F=k·raw+b`：R² ≥ 0.9995、重复性/迟滞 ≤ 0.5% FS；
5. 标定 JSON 写 `simulated=false`，双人签字归档。

## 三、单工况 6 步

1. 取排程行（电压/油门/桨型/重复）；
2. 设母线电压与油门，预热 30 s；
3. 采集 ≥3 s 稳态，记录环境量；
4. 存 raw + meta（`日期_组合_电压_油门_重复`），raw 只读；
5. 跑 `measured_readiness` 门禁 → `compute_efficiency` 处理；
6. 每 5 工况复测 1 点：偏差 ≤ 重复性离散度（或 ≤2σ），超限记原因。

## 四、异常处置

| 现象 | 处置 |
|---|---|
| 振动异常/异响 | 降油门→急停→查桨/紧固/动平衡 |
| 温度 > 80 ℃ 或冒烟 | 急停断电→电池移入防火袋→停止后续 |
| 电流超限/电源保护 | 降油门→查短路与接线 |
| 数据 NaN/跳变 | 该工况作废→查接线接地→记录 |

## 五、收工

断电 → 电池放电至存储电压 → 台架清洁归位 → 数据备份并校验 SHA256 → 当日记录（含异常）双人签字归档。

**数据纪律**：SIM/REFERENCE 不得进入 MEASURED 结论；门禁不通过的数据不得用于地图/论文。
