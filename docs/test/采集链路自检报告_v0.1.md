## 2. 用例与命令

```powershell
# 模拟采集 5 s @ 1000 S/s
py -3.12 code\acquisition\acquire.py --mode simulate --run-id 20261117_SIM_22V2_50pct_R1 `
  --duration 5 --sample-rate 1000 --operator "模拟联调" --combo DEMO `
  --voltage-set 22.2 --throttle-set 50 --repeat R1 --prop-diameter-m 0.4572

# 只读校验（3 s 稳态窗口，最低采样率 990 S/s）
py -3.12 code\acquisition\validate.py --input data\raw\20261117_SIM_22V2_50pct_R1.csv `
  --window 3 --min-sample-rate 990 --output data\metadata\20261117_SIM_22V2_50pct_R1.validation.json

# 回归测试（5 项）
py -3.12 -m unittest discover -s code\acquisition -p "test_*.py" -v
```

## 4. 局限（务必注意）

1. 模拟模式由程序生成正弦+噪声数据，不经过传感器、ADC、串口与时钟，**不能证明**硬件链路可用；
2. 未做砝码静态标定，raw 计数到物理量（N / N·m）的换算系数未知；
3. 时间戳为上位机时间，未验证 MCU 时钟抖动与长时间漂移；
4. 未测电磁干扰、串口丢包、隔离与接地效果；
5. `pass` 只表示"格式/连续性/采样率/稳态性"符合规则，**不等于**测量准确、标定合格或安全。
