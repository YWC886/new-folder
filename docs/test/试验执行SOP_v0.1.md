# 台架试验执行 SOP（标准作业程序）v0.1

> 适用：M0.4 最小采集链路与后续多工况测试（S2）· 编制 2026-11-21 · 执行前须经指导教师确认
> 配套：`docs/design/数据采集方案_DAQ_v0.1.md`、`docs/design/design_matrix_v0.2.md`、`docs/design/data_dictionary_v0.1.md`、`docs/test/静态砝码读数记录_v0.1.md`

## 1 目的与适用范围

规定单轴立式台架（推力 + 反扭矩臂）从**上电前检查**到**数据入库**的完整作业流程，确保：
- 人员与设备安全（防护罩、急停、双人、电池防火）；
- 力/扭矩量值可追溯（M1 砝码、加载+卸载、双人签字）；
- 数据可复现（固定母线电压、统一命名、raw 只读、门禁校验）；
- 每一步有记录、可复核、可交接。

本 SOP 只覆盖**地面静态测试**，不涉及外场飞行；室内台架测试不受《无人驾驶航空器飞行管理暂行条例》第 57 条飞行管理约束，但须遵守学校实验室安全规范。

## 2 角色与分工

| 角色 | 职责 |
|---|---|
| B（台架与硬件） | 台架搭建、防护、急停、电池管理；牵头安全；标定操作用砝码加载 |
| C（数据与软件） | 采集程序、参数设置、数据入库与门禁、异常记录 |
| A（组长） | 现场统筹、复核签字、异常决策；对外沟通 |
| 指导教师 | 方案与安全确认；关键节点到场或远程确认 |

**红线**：任何时刻至少 2 人在场；上电期间不得拆装、不得越过防护罩取物；电池出现鼓包/异味/温度异常立即断电并移入防火袋。

## 3 上电前检查清单

| 序号 | 检查项 | 责任 |
|---|---|---|
| 1 | 防护罩安装到位；急停按钮可切断电调供电回路（实测一次） | B |
| 2 | 桨叶无裂纹/缺口；紧固件扭矩复核；桨夹与电机座无松动 | B |
| 3 | 台架调平与对中：桨盘离地 ≥1.5D，下游 ≥1D 无遮挡；台面无工具杂物 | B |
| 4 | 线缆应力释放、远离旋转面；电池防火袋、灭火毯就位 | B |
| 5 | 可编程电源限流/过压保护设定正确；采集端接地与屏蔽检查 | C |
| 6 | 环境温湿度/气压记录（用于空气密度） | C |

## 4 静态砝码标定流程（双人）

1. 卸载：空载 → 按 0/20/40/60/80/100% FS 逐级加载，每点稳定后读 3 次；
2. 卸载：从 100% FS 逐级卸回，每点读 3 次（用于迟滞）；
3. 反扭矩通道同样处理，并记录力臂长度（0.25 m）；
4. C 现场拟合 `F = k·raw + b`，检查 R² ≥ 0.9995、重复性/迟滞 ≤ 0.5% FS；
5. 不达标则排查（零点漂移、接线、砝码放置偏心），重标；
6. 标定 JSON 写入 `simulated: false`，A 与 C 双人签字后归档 `data/metadata/`。

## 5 单工况执行流程

1. 从 `design_matrix_v0.2` 取下一行（order/电压/油门/桨型/重复）；
2. 设置母线电压（可编程电源）与油门指令；预热 30 s，确认转速/推力稳定；
3. 采集 ≥3 s（或按窗口配置）稳态数据，记录环境量；
4. 保存 raw CSV + meta.json（命名 `日期_组合_电压_油门_重复.csv`），raw 只读；
5. 运行 `measured_readiness.py` 门禁（标定/meta/表头/必需通道）；
6. 通过后 `compute_efficiency.py` 处理，产出 processed CSV + efficiency JSON；
7. 每 5 个工况做一次复测点（同工况重测），偏差须 ≤ 重复性离散度（或 ≤2σ），超限记录原因并复查。

## 6 异常处理

| 现象 | 处置 |
|---|---|
| 振动异常/异响 | 立即降油门→急停；检查桨叶、紧固、动平衡 |
| 电机温度 > 80 ℃ 或冒烟 | 急停、断电、移出电池；记录并停止后续测试 |
| 电流超限/电源保护 | 降油门、检查短路与接线；确认电源设定 |
| 数据异常（通道 NaN/跳变） | 停止该工况；复查接线/接地；该工况作废并记录 |
| 人员受伤 | 优先断电与急救，按学校应急预案上报 |

## 7 数据入库与复测判据

- 门禁通过：标定 `simulated:false`、meta `mode=="serial"`、表头与必需通道完整；
- 复测判据：复测值与地图预测偏差落在重复性离散度内（或 ≤2σ）；
- 所有 SIM/REFERENCE 标记的数据不得进入 MEASURED 通路的正式结论；
- 每日收工前备份 raw 与 metadata，并校验 SHA256。

## 8 收工检查

断电 → 电池放电至存储电压（3.8 V/cell 左右）→ 台架清洁归位 → 数据备份与校验 → 当日记录（含异常）双人签字归档。
