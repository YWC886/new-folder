一系统启动时序 — 从上电到主循环

启动概述：系统上电复位后，Cortex-M4 自动加载 MSP、跳转 Reset_Handler，完成数据段拷贝和 BSS 清零后调用 SystemInit() 和 main()。所有外设在 mcu_peripheral_init() 中依次初始化，之后进入 while(1) 主循环，仅做 CAN 数据上传。所有实时控制逻辑均由中断驱动。

1.1 启动阶段详细步骤

🔑 关键设计点

  • 主循环仅做 CAN 数据上传，所有电机实时控制 (电流环/速度环/状态机) 均在中断中完成
  • CAN 初始化前检查 HEXT_STABLE_FLAG，不稳定则死循环 — 因为 CAN 协议要求时钟精度 ≤1.58%，内部 HICK 不满足
  • PWM 输出在 START 状态完成后才使能 (调用 motor_ctrl_start_pwm())，初始化阶段 GPIO 为输入态

二中断向量表与优先级体系

2.1 NVIC 优先级分组配置

优先级分组：NVIC_PRIORITY_GROUP_4 — 4位全部用于抢占优先级 (0~15)，不支持子优先级。

这意味着高抢占优先级的中断可以嵌套打断低优先级中断，同优先级的中断按向量表顺序仲裁，不可互相嵌套。

2.3 中断嵌套关系图

⚠ 中断优先级设计原则

  1. SysTick (Prio 0) 最高 — 状态机和保护逻辑不能被打断
  2. PWM输入 (Prio 0) 最高 — 同优先级，确保脉宽测量的实时性
  3. Hall捕获 (Prio 1) 第二高 — 位置信息必须及时：Hall中断可以打断ADC中断
  4. ADC1_2 (Prio 2) 第三高 — FOC核心控制链，保证在每个PWM周期内完成
  5. TMR6 (Prio 3) 第四 — PWM信号丢失检测，超时触发频率低
  6. CAN RX (Prio 4) 最低 — 通信不紧急，不能影响实时控制

5.3 启动阶段特殊时序

启动强制低速阶段 (StartVoerFlag 机制)

目的：防止电机启动时瞬间大电流冲击，在速度建立起来之前保持低速。

  1. 进入 NORMAL_OPERATION 后，前1秒强制将 ESC 油门指令设为 14 (Esc_Cmd=14)
  2. 等待实际转速 |velocity.real_velocity| > 0.13 (650 RPM)
  3. 当速度超过650RPM后，开始计数 StartTime，维持1秒 (计数到1000)
  4. 1秒后 StartVoerFlag = 1，切换到实际油门指令

🔑 分段PI关键设计

  • 切换依据：使用 目标转速 (set_demand_velocity) 而非实际转速 — 在 SysTick (1kHz) 中计算
  • 积分清零：低速段和过渡段都清 velocity_pid.sum = 0，防止积分累积导致过冲
  • 速度基值：BASE_SPEED = 5000 RPM，归一化值 = 实际RPM / 5000
  • 电流环 PI：全程固定 — Kp=1.2, Ki=0.08, Kb=0.2 (d轴和q轴相同基值)
  • 加速度分段：目标速度 > 1150RPM (0.23pu) 时 ADDVAL=0.0012，否则 ADDVAL=0.0004

6.2 抗积分饱和PI算法

// 增量式PI + Back-Calculation 抗积分饱和 (motor_pid_calc)
void motor_pid_calc(float ref, float fdb, float* out, PID_UDT* pid)
{
    float err = ref - fdb;                           // ① 计算偏差
    float temp = pid->sum + pid->kp * err;            // ② 比例 + 积分输出

    // ③ 输出限幅 (防止饱和)
    if(temp > pid->max_out) *out = pid->max_out;
    else if(temp < pid->min_out) *out = pid->min_out;
    else *out = temp;

    float exc = temp - *out;                          // ④ 饱和差值
    pid->sum = pid->sum + pid->ki * err - pid->kb * exc;  // ⑤ 积分更新 (Kb退饱和)
}

// PI 参数结构
typedef struct {
    float kp, ki, kb;        // 比例/积分/退积分系数
    float max_out, min_out;   // 输出限幅
    float sum;               // 积分累加器
    float err;               // 当前偏差
} PID_UDT;

一阶低通滤波器公式

y[n] = K1 × y[n-1] + K2 × x[n]
其中:
  K1 = 1 / (1 + Ts × 2π × fc)
  K2 = 1 − K1
  Ts = 采样周期, fc = 截止频率

示例 (电流LPF, fc=5000Hz, Ts=62.5μs):
  K1 = 1 / (1 + 0.0000625 × 2π × 5000) = 1 / (1 + 1.9635) ≈ 0.337
  K2 = 1 − 0.337 = 0.663
