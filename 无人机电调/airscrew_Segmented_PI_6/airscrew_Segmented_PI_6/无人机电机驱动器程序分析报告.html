一、项目总体概述

本项目是一个基于FOC（Field Oriented Control，磁场定向控制）算法的无人机用无刷直流电机（BLDC/PMSM）电子调速器（ESC）固件程序。系统采用Artery（雅特力）AT32F403A/407系列ARM Cortex-M4微控制器，主频240MHz，通过霍尔传感器获取转子位置信息，使用分段PI控制策略实现电机速度闭环控制。系统支持CAN总线和PWM信号两种控制方式，适用于多旋翼无人机动力系统。

1.2 关键特性

  • FOC磁场定向矢量控制，支持SVPWM空间矢量调制
  • 分段PI速度控制器：根据转速自动切换PI参数，实现全速域最优控制
  • 基于霍尔传感器的转子位置估计
  • Luenberger运动观测器实现角度滤波和平滑
  • CAN总线通信（默认500Kbps，支持1Mbps~50Kbps多档切换）
  • PWM信号输入（标准RC电调信号 1040-1940μs）
  • 完备的保护机制：过流、过压/欠压、堵转、Hall异常检测
  • 弱磁控制支持（Field Weakening）
  • 母线电压/电流实时监测

八、FOC矢量控制算法

系统采用标准FOC（磁场定向控制）算法，包含完整的坐标变换链。所有计算均采用标幺化（Normalized），基值电流=100A，基值速度=5000RPM。

8.1 FOC变换链

步骤变换名称公式
1 Clarke变换
三相静止 → 两相静止		 Iα = Iu
Iβ = (Iu + 2·Iv) / √3
2 Park变换
两相静止 → 两相旋转		 Id = Iα·cos(θ) + Iβ·sin(θ)
Iq = -Iα·sin(θ) + Iβ·cos(θ)
3 PI电流控制
在d-q坐标系中		 Id_ref = 0 (Id=0控制策略)
Iq_ref = 速度环输出
4 逆Park变换
(含1.5Ts延迟补偿)		 Vα = cos(θ+1.5ωTs)·Vd - sin(θ+1.5ωTs)·Vq
Vβ = sin(θ+1.5ωTs)·Vd + cos(θ+1.5ωTs)·Vq
5 逆Clarke变换
两相静止 → 三相静止		 Vu = Vβ
Vv = (√3·Vα + Vβ) / 2
Vw = (√3·Vα - Vβ) / 2
6 SVPWM调制
电压 → PWM占空比		 扇区判断 → 时间计算 → PWM比较值

8.2 SVPWM实现

系统提供了两种SVPWM实现，当前使用归一化的TI风格SVPWM：

  • motor_foc_svpwm()：基于扇区判断的传统七段式SVPWM（需传入母线电压进行换算）
  • motor_foc_svpwm_normal()：归一化的TI风格SVPWM（当前使用），电压基准为Udc/√3 = 1

电压圆限制：MAX_VOLT_CIRCLE_LIMIT = 0.81，防止过调制，保障调制波形不失真。

九、闭环控制结构

系统采用级联式双闭环控制结构：外环为速度环，内环为电流环。速度环的输出作为q轴电流给定值，电流环输出d-q轴电压指令，再经SVPWM调制生成PWM占空比。

9.2 电流环执行流程

电流环在每次ADC转换完成后（16kHz）执行：

  1. 读取ADC寄存器获取三相电流原始值（CURR_PHASE_A/B/C_REGISTER）
  2. 减去偏置值，乘以换算因子（SAMPLE_CURR_CON_FACTOR / BASE_CURRENT）
  3. 应用5kHz一阶低通滤波器
  4. 执行Clarke变换 → Park变换，得到Id和Iq
  5. d轴PI控制：Id_ref=0（Id=0控制策略，最大转矩电流比）
  6. q轴PI控制：Iq_ref来自速度环输出
  7. 电压圆限制：计算可用Vq_max = sqrt(0.81 - Vd²)，经100Hz低通滤波
  8. 执行逆Park变换：含1.5Ts采样延迟补偿（motor_foc_invpark_delay_compensation）
  9. SVPWM调制 → 输出PWM占空比到 TMR1->c1dt/c2dt/c3dt
  10. 计算母线电流估算值：ibus = f(Ta,Tb,Tc, Iu,Iv,Iw)

9.3 速度环执行流程

速度环每10个PWM周期（1.6kHz）执行一次：

  1. 从hall2angle.pll_speed_rpm_filter获取滤波后的实际转速
  2. 归一化：real_velocity = speed_rpm / BASE_SPEED (5000)
  3. 调用分段PI控制器：motor_pid_calc(demand_velocity, real_velocity, &iq_demand, &velocity_pid)
  4. 电流环：motor_current_ctrl() 嵌套执行

十、分段PI控制器（Segmented PI）

这是本项目的核心特色——根据电机转速实时调整速度PI控制器的Kp和Ki参数。在低速、中速、高速区域使用不同的PI参数组，中速区域采用线性插值过渡，实现全速范围内的最优控制性能和最小超调。

10.1 PI算法实现

motor_pid_calc() 实现带有抗积分饱和（Anti-Windup / Back-Calculation）的增量式PI算法：

  1. err = ref - fdb (计算偏差)
  2. temp = sum + Kp × err (比例+积分输出)
  3. out = clamp(temp, min_out, max_out) (输出限幅)
  4. exc = temp - out (计算饱和差值)
  5. sum = sum + Ki × err - Kb × exc (积分更新，Kb项实现退饱和)
PI参数结构体 (PID_UDT)：包含 Kp(比例), Ki(积分), Kb(退积分/微分前馈), max_out, min_out, sum(积分累加器), period, err

11.2 状态转换

  1. INIT(0) → 初始化各模块 → STOP(1)
  2. STOP(1) → CAN指令≥12启动阈值 → start标志 → START(2)
  3. START(2) → 采集128次ADC偏置值 → 计算平均值 → 使能PWM输出 → NORMAL_OPERATION(8)
  4. NORMAL_OPERATION(8) → 速度环+电流环闭环控制

启动阶段的特殊处理：

  • 启动后前1秒，强制将油门设为14（低速），等待电机转速超过约650RPM后切换到实际油门
  • 如果油门信号低于12（停止阈值），触发disable信号 → STOP

停机流程：

  • CAN指令 ≤ 11 (CMD_STOP_TH) → disable标志 → STOP（快速停机）
  • 或 stop标志 → RAMP_DOWN → 速度降至0 → STOP（慢速斜坡停机）

12.2 已实现的保护功能

  • 过流保护：motor_protect_bus_current() 检测 ibus > 10A
  • Hall异常检测：Hall值0或7持续20次，置error_flag（当前仅标记，未触发停机）
  • 速度限制：超过4600RPM后，禁止加速度继续增大
  • PWM信号丢失检测：TMR6 3ms超时检测
  • 电压圆限制：Vd²+Vq² ≤ 0.81，防止过调制
  • CAN时钟保护：HEXT不稳定时进入死循环，防止CAN通信异常

十三、运动观测器与滤波器

13.1 Luenberger运动观测器 (LB_MotionObserv)

龙伯格型运动观测器，对Hall传感器计算出的原始角度进行滤波和平滑，该观测器是一个二阶状态观测器，基于简化的电机运动方程：

  • J · dω/dt = TE + TL （转动惯量×角加速度=电磁转矩+负载转矩）
  • dθ/dt = ω
参数值
比例增益 Kp12,980
积分增益 Ki10.0
微分增益 Kb16.57
惯量倒数 Inertia_Inv189.4
计算周期 Ts62.5 μs (PWM_FOC_PERIOD, 16kHz)

观测器输入输出：

  • 输入：ActTheta（原始Hall角度 0~2π）、TE（电磁转矩，当前恒为0）
  • 输出：EstTheta（估计角度）、EstSpd_Filt（滤波转速）、EstMechTheta（机械角度）

角度计算流程（motor_hall_to_angle_cal）：

  1. 低速时（<最小Hall转速）：直接使用Hall边沿角度
  2. 正常转速时：raw_angle = hall_edgeAngle + ω_filtered × capture_time
  3. 角度限制在 (hall_edgeAngle ± π/3) 范围内
  4. 将原始角度输入Luenberger观测器进行滤波
  5. 输出滤波后的角度和速度

十五、程序执行流程

15.1 主程序 (main.c)

main()函数极简——仅执行外设初始化和CAN数据更新主循环。所有实时控制逻辑都通过中断驱动：

int main(void)
{
    mcu_peripheral_init();    // 外设初始化
    while(1)
    {
        can_updata();           // CAN数据上传 (500Hz)
    }
}

15.2 mcu_peripheral_init() 初始化顺序

  1. system_clock_config() —— 系统时钟配置 (HEXT 12MHz → PLL 240MHz)
  2. systick_clock_source_config() —— SysTick时钟源 AHB/8
  3. SysTick_Config() —— SysTick 1ms中断
  4. nvic_priority_group_config() —— 优先级分组4 (4位抢占优先级)
  5. timer5_init() —— TMR5初始化 (32位, 20MHz, Hall圈时测量)
  6. pwm_init() —— TMR1 PWM初始化 (16kHz, 6路互补输出+CH4触发)
  7. hall_init() —— TMR3 Hall捕获初始化
  8. adc_config() —— ADC1/ADC2初始化 (4通道, TMR1 CH4触发)
  9. PWM_Input_Init() —— PWM信号输入捕获 (PB3/TMR2/TMR6)
  10. can_configuration() —— CAN1初始化 (500Kbps)
